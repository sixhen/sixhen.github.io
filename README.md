## 🌟 Tổng quan dự án (Overview)

**sixhen.github.io** là website portfolio cá nhân được thiết kế và tối ưu theo trường phái **Cyber-Bento 2026**, kết hợp giữa triết lý tối giản của hệ thống Linux/Termux và trải nghiệm thị giác vị lai.

> 🤖 **Tuyên ngôn AI:** Toàn bộ kiến trúc giao diện, hiệu ứng hạt, mã lệnh giả lập Terminal CLI và cấu trúc mã nguồn đều được **kiến tạo và tối ưu hóa 100% bằng Trí tuệ Nhân tạo (AI)**.

---

## ⚡ Tính năng nổi bật (Key Features)

- **🎨 Cyber-Bento Grid & Spotlight Cursor:** Các khối thẻ Bento tương tác phản chiếu ánh sáng động theo vị trí trỏ chuột (`mouse tracking radial gradient`).
- **💻 Live Interactive Terminal CLI:** Giả lập môi trường dòng lệnh Termux (`sixhen@arch-arm64:~`) cho phép người dùng trực tiếp gõ các lệnh `help`, `skills`, `projects`, `contact`, `donate`, `clear` ngay trên trình duyệt.
- **🌌 60FPS Ambient Particle Mesh:** Canvas tương tác đa chiều chuyển động mượt mà, siêu nhẹ, không phụ thuộc thư viện nặng.
- **📱 Responsive 100%:** Tương thích chuẩn xác từ màn hình di động Android/iOS đến màn hình 4K desktop.
- **💳 Cổng VietQR MB Bank:** Tích hợp sinh mã QR động của Ngân hàng Quân Đội (MB Bank) kèm tính năng phóng to Modal và sao chép số tài khoản 1-chạm.
- **🚀 Zero Dependencies:** Sử dụng thuần HTML5, Modern CSS Variables, và Vanilla JavaScript cho tốc độ tải trang dưới 0.5s.

## 💻 Hướng dẫn chạy thử trên máy (Local Development)

Không cần cài đặt phức tạp, bạn có thể chạy thử trực tiếp bằng Python:

```bash
# Clone repository về máy
git clone https://github.com/sixhen/sixhen.github.io.git
cd sixhen.github.io

# Khởi chạy local server tại cổng 8000
python -m http.server 8000
```

Mở trình duyệt truy cập: `http://localhost:8000`
